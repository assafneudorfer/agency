# Agency brand

`logo.svg` is the Agency mark: a letter A with a spark (the AI) above a building block (the app), white on indigo `#5b5bf0`. It was generated with Higgsfield (GPT Image 2.5) and traced to a vector, so it stays sharp at any size. `logo-512.png` is a raster copy for places that need one.

The platform serves the same files from `platform/web/` as the favicon, the Apple touch icon and the logo in the sidebar and sign-in page.
