# ABCDE ומסע

מיון פנימי של מוכנות / תחום. **לא** חמש לשוניות בממשק למשתמש.

## מפת תוויות

| קוד | בפנים | למשתמש |
|---|---|---|
| A | עבודה וכסף | עבודה |
| B | בית ויום־יום | בית וחיי יום־יום |
| C | קהילה ושייכות | קהילה |
| D | מקצוע, רישוי, ניירת | מקצוע ומסמכים |
| E | עברית ולמידה | עברית ולמידה |

## איך כותבים לעולה / למשתמש

- כתוב **«הצעד הבא»** ו**«למה»**.
- אל תציג ציון כמו במבחן, אחוז מוכנות מאיים, או דירוג שמבייש.
- אפשר לשמור ראיות פנימיות (מקור, תאריך, ביטחון) מאחורי הקלעים.

## בכלים שנבנים כאן

- מיון לוח / סינון לפי ABCDE — בסדר כמיון פנימי או כתווית קצרה.
- בכרטיס הכלי (`tsion-tool.json`) שדה `abcde` משתמש בקודי `A`–`E`.
- שלב במסע (`journeyStage`) נפרד מ־ABCDE: שלב = מתי בדרך; ABCDE = באיזה תחום.
