# Agency brand

`logo.png` is Agency's mascot, Axel the axolotl detective: a pink axolotl in a navy fedora and trench-coat collar, on the UI's indigo `#5b5bf0`. An axolotl starts with A, like Agency, and the detective hat stands for the agent that digs through your data and builds the app. It was generated with Higgsfield (GPT Image 2.5) and cropped to a 192px rounded-square icon with a transparent background.

The platform serves the same file from `platform/web/` as the favicon, the Apple touch icon and the logo in the sidebar and sign-in page.
